# Project Management Learning Board (Agile & Scrum)

This repository documents my structured learning journey in Project Management, with a focus on Agile and Scrum fundamentals, estimation techniques, mindset, and practical tools.

The learning content is organized and tracked using a Trello board, where topics, notes, and resources are structured as part of my ongoing internship and professional development.

## Topics Covered
- Agile fundamentals and principles
- Scrum framework (roles, events, artifacts, values)
- Agile estimation and planning (story points, velocity, planning poker)
- User stories and backlog refinement
- Growth mindset and continuous learning
- Innovation and case studies
- Strategic analysis tools (SWOT analysis)
